COMPLAINT SERVICE SYSTEM - BACKEND API DOCUMENTATION

This document defines the REST API endpoints required for the Complaint Service System. The system supports four user roles: Customer, Admin, Dealer, and Service Person (Technician).

================================================================
AUTHENTICATION APIs
================================================================

1. Send OTP
   - Endpoint: POST /api/auth/send-otp
   - Description: Sends a one-time password to the user's mobile number.
   - Request Body:
     {
       "phone": "+919876543210"
     }
   - Response:
     {
       "status": "success",
       "message": "OTP sent successfully"
     }

2. Verify OTP
   - Endpoint: POST /api/auth/verify-otp
   - Description: Verifies the OTP and returns an authentication token.
   - Request Body:
     {
       "phone": "+919876543210",
       "otp": "123456"
     }
   - Response:
     {
       "status": "success",
       "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
       "user": {
         "userId": "usr-101",
         "name": "S. Siva",
         "role": "Customer",
         "isProfileComplete": false
       }
     }

3. Profile Setup
   - Endpoint: POST /api/auth/profile-setup
   - Description: Completes the user profile after the first login.
   - Request Body:
     {
       "name": "S. Siva",
       "email": "siva@greenacres.in",
       "address": "Zone 3, Thudiyalur Road, Coimbatore",
       "role": "Customer"
     }
   - Response:
     {
       "status": "success",
       "user": {
         "userId": "usr-101",
         "name": "S. Siva",
         "email": "siva@greenacres.in",
         "phone": "+919876543210",
         "address": "Zone 3, Thudiyalur Road, Coimbatore",
         "role": "Customer",
         "isProfileComplete": true
       }
     }
